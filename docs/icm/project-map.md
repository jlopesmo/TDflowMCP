# TDflowMCP — Project map

The visual diagnostics workflow fixture is `tests/td/run_td_diagnostic_tests.py` with its in-process driver `tests/td/td_runner_diagnostics.py`. It uses disposable projects and the existing MCP harness. [Milestone](../milestones/v1.3-visual-diagnostics.md)

The v1.4 recovery checks extend the existing `tests/td/run_td_mcp_tests.py` suite. The component suite pairs an external wire refusal with an owner-connected consumer and verifies the custom control's effect. [Milestone](../milestones/v1.4-workflow-recovery.md)

The v1.5 guidance data lives in `src/tdflowmcp/opguides.py`. The disposable probe `tests/td/run_td_script_lifecycle_probe.py` gathers runtime parameter facts and Script staging observations. The component suite exercises the existing procedural authoring tools and new catalog response. [Milestone](../milestones/v1.5-procedural-authoring.md)

The disposable Network Editor API probe is `tests/td/run_td_network_pane_probe.py`. [Milestone](../milestones/v1.6-network-vision.md)

The scoped diagram's pure PNG renderer is `src/tdflowmcp/network_diagram.py`. Its disposable TouchDesigner acceptance uses `tests/td/run_td_network_visual_tests.py` and `tests/td/td_runner_network_visual.py`. The isolated client fixture lives in `tests/td/network_vision_clients.py`. [Validation](validation-index.md#v16-network-visual-inspection-development)

The v1.7 inert draft review prototype is `spikes/v17/script_intent.py`. The disposable export, import and restart probe runs from `tests/td/run_td_advanced_script_probe.py`. These files are outside the packaged runtime. [Milestone](../milestones/v1.7-script-access.md)

Issue #24 adds `spikes/v17/transfer_review.py` for inert manifests, `spikes/v17/recovery_ledger.py` for the SQLite recovery experiment, and `spikes/v17/probe_windows_integrity.py` for the synthetic Windows integrity comparison. `tests/td/run_td_script_boundary_probe.py` runs the disposable native checks. `tests/unit/test_script_transfer_recovery.py` covers transfer, authorization and interrupted ledger cases. [Milestone](../milestones/v1.7-script-access.md#issue-24-boundary-and-recovery-follow-up)

Issue #26 adds the packaged pure-Python workspace in `src/tdflowmcp/drafts.py` with a store-worker entry point and the dashboard's Script drafts tab. Targeted verification lives in `tests/unit/test_offline_drafts.py` and `tests/td/run_td_offline_drafts.py`, with `tests/td/td_runner_offline_drafts.py` for in-process observations. [Offline milestone](../milestones/v1.7-offline-script-drafts.md)
