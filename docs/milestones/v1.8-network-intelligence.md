# TDflowMCP v1.8 Network intelligence

[Issue #29](https://github.com/jlopesmo/TDflowMCP/issues/29) approves passive development work on `dev` with Windows and TouchDesigner 2025.32440. [ADR-0021](../decisions/0021-compact-network-inspection.md) records the proposed design.

## First batch

Use the existing network description for compact multi-level inspection, scoped search and exact native wire indexes. Trace selected stored parameter and CHOP channel references as static candidates. Confirm the relevant parameter through named reads. Continue to use the existing checkpoint and handoff tools after owner changes.

The baseline and candidate share a disposable nested TOP and CHOP fixture. The tasks cover the signal chain, a zero-opacity control across components, a recorded error and a change after a checkpoint. Run the scripted workflows and real Claude Code and Codex. Report exact facts, tool calls, HTTP response bytes, RPC time and observed client elapsed time separately. Record token use only from client telemetry.

## Validation and limits

Verify read scopes and protected operators, hidden graph edits, parameter source restrictions, page and work bounds, current authorization, audit, kill switch, minimized-window behavior, legacy clients and native cook/callback passivity. Keep dependency authentication and audit within the existing tool engine. [Tool surface](../architecture/tool-surface.md#compact-network-inspection) · [Security model](../architecture/security-model.md)

The existing fingerprint path detects the fixture's owner edit with one resume call. Its per-operator digest includes native input paths before the resume response is filtered. A changed unreadable wire can therefore affect the digest of the readable endpoint. A new summary needs a permission-bound comparison with explicit rules for policy changes between observations. Defer it along with catalog expansion and broader expression analysis.

The `1.8.0.dev1` component in `build/v1.8.0-dev1/` passed 62 network checks, including both real clients, on Windows with TouchDesigner 2025.32440. The results record the matched before-and-after performance and the remaining work-limit caveat. Release approval and acceptance of ADR-0021 are separate owner decisions.
