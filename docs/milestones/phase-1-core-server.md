# Phase 1 — Secure core server (proposed plan)

**Status: Proposed.** Requires owner decisions D1, D2 and D7 ([roadmap](../icm/roadmap.md#owner-decisions-pending)). Nothing here is implemented.

## Goal
A `TDflowMCP.tox`, built from source, that exposes a small MCP tool surface over loopback Streamable HTTP. It has per-agent tokens, deny-by-default scoped CRUD+execute, undo, a kill switch, and a hash-chained audit log, all proven by automated tests. Primary client: Claude Code.

## Phase 1 acceptance criteria
1. An agent with `read`+`update` on `/project1/fx/**` can change a parameter **value** there. It is **denied**, with a `deny` audit event, when: targeting `/project1/out1`; deleting anything; setting a parameter **expression**; writing an Execute DAT's text; or targeting any TDflowMCP instance or its ancestors' flags.
2. A request with a foreign Origin, or a loopback Origin on a different port, returns 403 before any tool logic runs.
3. The component refuses to start if a loopback-only bind cannot be verified.
4. Each mutating call that S4 shows TD can undo is undone by `tdflow_undo` while it is on top of the undo stack, and its audit row links to the undo label. Interleaved edits return `UNDO_CONFLICT`. Limits found by S4 are documented.
5. Audit verification detects a manually altered row relative to the last checkpoint. Mutations fail closed when the audit store is unavailable.
6. The kill switch rejects all agent calls until cleared.
7. The `.tox` is built from a clean checkout by documented commands on the declared minimum TD build, and its sha256 is recorded.
8. Unit tests (CI) and in-TD tests (local, recorded with the TD build number) pass. Results are recorded in `validation-index.md`.
9. ICM updated: `current-state.md`, `project-map.md`, `validation-index.md`, `tool-surface.md`.

## Explicitly not in Phase 1
Dashboard UI, approval flow (`require_approval` resolves to deny), Code Mode, experiments/snapshots, raw exec, project saving, extensions, OAuth, remote access, stdio shim, Claude Desktop support.
