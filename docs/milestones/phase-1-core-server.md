**Status:**
- Scope and sequencing: **Conditionally Accepted** (owner, 2026-11-22, [ADR-0001](../decisions/0001-product-scope.md)).

**1A acceptance** (all verified 2026-11-22 by the in-TD suite on 2025.32440; drop-in is exercised with `loadTox`, the same component-load path):
1. Dragging a **dev build** `.tox` (produced by the S2 builder; release packaging is 1C item 24) into a fresh disposable project and pulsing `Opensetup` shows the Setup page. No listener exists before the pulse.
2. No application request is served before the effective loopback-only binding is verified (requests during `VERIFYING` get 503), and failed or ambiguous verification closes the listener immediately. Port 9480 conflicts are reported and the port is never changed silently.
3. All checks show pass/warn/fail/unknown with evidence. Every fail has remediation text. No check performs an install or a configuration change.
4. `/mcp` returns `MCP_DISABLED`. Foreign and other-port Origins return 403.
5. No parameter value or generated text contains a secret (test).

**1B acceptance:**
1. An agent with `read`+`update` on `/project1/fx/**` can change a parameter **value** there. It is denied, with audit, on every other case: `/project1/out1`, deletes, expressions, Execute DAT text, TDflowMCP instances or ancestor flags, and `tdflowProject` via raw tools.
2. Each mutation that S4 shows TD can undo is reversible via `tdflow_undo`; interleaved edits return `UNDO_CONFLICT`.
3. Audit tamper detection works relative to a checkpoint, and mutations fail closed without audit.
4. The kill switch rejects all agent calls.
5. Session logs persist across a TD restart (in `Datadir`).
6. In-TD tests are recorded with the TD build number.
