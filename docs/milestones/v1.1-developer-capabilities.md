## Acceptance criteria

- Inspect and edit Python expressions, including literal operator references and transitions back to constants. Check syntax and bounded references without evaluating candidate code. Bind approval to the exact call, target identity, prior state and policy. Report runtime diagnostics available from TouchDesigner and verify rollback.
- Inspect, compare, validate, revise and restore Python DAT source through the existing DAT tools. Stage supported callback DATs inactive where feasible. Show the code and relevant activation state before approval. Preserve snapshot durability, scope checks, revocation, suspension and fail-closed auditing.
- Investigate Script CHOP, SOP and TOP staging in a disposable project. Management stays unavailable unless the existing enforcement model can support it and staging, actual activation and recovery pass validation. Escalate any design that changes an accepted security decision.
- Exercise the development workflow on a procedural TOP network and an approved callback, including invalid code, correction, stale state, approval cancellation, revocation, suspension, audit failures, protected paths and undo. Validate the packaged component in TouchDesigner 2025.32440 on Windows and run real Claude Code and Codex MCP checks where practical.
- Obtain independent security and usability reviews. Apply the release-blocking finding thresholds in the owner's brief, run the packaged regressions, and observe passing Windows and Ubuntu CI before release integration.
- Follow the [release procedure](../operations/verification-and-release.md). The owner approved a v1.1.0-only exception on 2026-11-26 for Windows with TouchDesigner 2025.32440. Confirm the final tagged package before publishing. Verify the versioned and compatibility downloads, manifest, checksums and installation guide on both GitHub-hosted platforms, then synchronize `dev` and `main`.

## Independent review

The first security review held publication. It identified a High finding in dispatch authorization, Medium findings in credential revocation, callback visibility, runtime identity and legacy undo, and a usability finding about deactivation when the preview is refused. The follow-up confirmed the token-scoped approval, runtime binding, preview and legacy-undo changes, and identified a dispatch window during lease handling. The final review confirmed that execution and undo refresh authorization after resolving leases. It independently ran four regressions covering revocation during lease handling, revocation and suspension during resolution, token rotation and runtime-bound approvals. All four passed. The reviewer confirmed the owner fallback through the Execute DAT's native Active parameter and closed the release-blocking findings in the reviewed scope. Packaged verification remains a release gate.

The independent recovery review found that the TOP read guard accepted the lock state on unverified builds and that the recovered tests observed cooks without a Python callback counter. The re-review confirmed that both paths now check Windows and TouchDesigner 2025.32440 before reading the output and that the disposable fixture observes both cook and callback counts. The independent usability re-review confirmed the corrected installation guide, Skill and capture instructions.

## Script operator investigation

Script CHOP, SOP and TOP use callback DATs selected by the operator and can run when TouchDesigner cooks the network. The v1.1 candidate retains the existing creation allowlist. On 2025.32440 the disposable probe found a factory callback DAT on each, zero cooks while their parent was inactive, and one cook each after the parent was enabled and the operator explicitly cooked. A supported Script workflow still needs an owner-approved design for stable callback ownership, staging and activation without changing the cook state of an unrelated network. A separate probe found that reading `.text` cooked a Script DAT. The packaged source guard refused that read and the project-memory regression refused computed records without cooking them.
