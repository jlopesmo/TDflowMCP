# TDflowMCP v1.5 procedural authoring

[Issue #14](https://github.com/jlopesmo/TDflowMCP/issues/14) follows the verified v1.4 release. It authorizes a disposable Script lifecycle prototype and an offline guide to locally supported authoring. Active Script authoring needs a separately accepted security decision. [ADR-0018](../decisions/0018-script-operator-lifecycle.md)

## Observed lifecycle boundary

The disposable Windows project in TouchDesigner 2025.32440 created one Script CHOP, SOP and TOP under a cook-disabled Base COMP. The factory callbacks were authored Text DATs. Ownership inspection and reading the scoped, directly authored source left all cook and callback counters at zero. The normal Setup Parameters pulse advanced each cook counter to one while the parent was still disabled. The benign instrumented callbacks did not report executions in that observation. A later owner edit changed the selected callback DAT while the factory DAT was still docked on each operator.

The no-cook gate and docking-based ownership assumption therefore failed. Active Script authoring stays deferred. The product still supports approval-gated expressions and the existing six Execute DAT types. [Validation](../icm/validation-index.md#v15-procedural-authoring-development)

## Offline guidance and authoring

The existing operator catalog accepts opt-in `guidance: true`. It reports the verified runtime and coverage with concise uses and selected parameter names, labels and styles for seven supported operators. Start with this guidance, then verify actual values, modes and limits against the chosen instance. The fixture compares an animated texture, CHOP-driven opacity, an approved Parameter Execute DAT, and exact recovery against the v1.4 package.

The Windows and TouchDesigner 2025.32440 comparison passed on both packages. The new guide moved the Math CHOP parameter lookup ahead of creation. Each run took 24 MCP requests and five approvals, so this comparison establishes earlier discovery. It shows no call-count or approval-count savings. The candidate verified the changed pixels, one approved callback execution, and restoration after an exact audit-sequence undo. [Validation](../icm/validation-index.md#v15-procedural-authoring-development)
