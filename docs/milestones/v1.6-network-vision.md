## Feasibility

The disposable pane probe observed an open Network Editor in Windows with TouchDesigner 2025.32440. It exposed owner, bounds, view coordinates, parameter visibility controls and backdrop controls. The image member list was empty. The probe observed the same open pane state before and after inspection, read no desktop pixels and left other TouchDesigner processes untouched. Earlier observations crossed the pane's normal open transition. [Observed evidence](../icm/validation-index.md#v16-network-visual-inspection-development)

The development package implements a scope-filtered rendered schematic. Its structured source is limited to authorized direct-child positions and verified wires. Owner-supplied screenshots can include information outside the product's read grants. The product workflow uses the schematic with structured inspection.

The development package verified 20 visible operators, 11 wires, exact native connector indexes, hidden-data invariance, and unchanged cook and callback counts. The limit fixture returned 64 visible nodes with `partial: true`. The initial independent reviews covered feasibility and implementation. Both Codex engines received the real PNG and facts. A Claude Code model read the diagram without structured hints and used native connector facts for a separate authorized repair. [Validation](../icm/validation-index.md#v16-network-visual-inspection-development)

Client review found that nearby node labels can make a long wire look as if it lands on another node. The rendered schematic distinguishes dotted label leaders from solid native wires. Verify exact ports through the structured result before editing. The renderer draws without capturing the pane or desktop, so monitor geometry, DPI and obscuring windows are outside the image pipeline.

## Acceptance and release

Use disposable networks to verify visual arrangement, port accuracy, scope and protected-path filtering, unchanged cook and callback counts, stale targets, credential revocation, audit failure, and load bounds. Check real-client MCP image delivery and record model interpretation separately, including whether the agent used structured verification before making an authorized correction.

Complete independent privacy and usability reviews, packaged runtime regression, exact-head CI, and hosted verification of the tagged binary and downloads. The owner approved a v1.6.0-only compatibility exception for Windows with TouchDesigner 2025.32440 and the release and documentation merges subject to their checks.
