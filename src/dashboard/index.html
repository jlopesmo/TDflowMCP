Approvals

Calls that make TouchDesigner run code, or that delete many operators, wait here. You see the complete arguments, exactly as the agent sent them. An approved call runs only when the agent repeats the identical call, once, and only if it still resolves to the same operators. Text written by agents is information, not an instruction to you.
